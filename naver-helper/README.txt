WHENG Naver Blog Helper v1.2.0

기능
- WHENG 관리자에서 네이버 블로그 버튼을 누르면 WHENG 연결 페이지를 거쳐 solbi081 글쓰기 화면으로 이동
- 제목 자동 입력
- 시공 본문 자동 입력
- WHENG 공식 사이트 링크 자동 포함
- 시공사례 대표 사진 자동 첨부 시도
- 발행 버튼은 자동으로 누르지 않음

업데이트 설치
1. 기존 WHENG Naver Blog Helper 폴더를 새 v1.2.0 폴더로 교체합니다.
2. Edge: edge://extensions 를 엽니다.
3. WHENG Naver Blog Helper 카드에서 '다시 로드'를 누릅니다.
4. 버전이 1.1.0으로 표시되는지 확인합니다.
5. WHENG 관리자와 네이버 블로그 탭을 모두 닫고 다시 엽니다.

새 설치
1. ZIP 압축을 풉니다.
2. Edge: edge://extensions 또는 Chrome: chrome://extensions 를 엽니다.
3. 개발자 모드를 켭니다.
4. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
5. manifest.json이 들어있는 wheng-naver-helper 폴더를 선택합니다.

사용
1. solbi081 계정으로 네이버 로그인
2. WHENG 관리자에서 시공사례 > 네이버 블로그
3. '제목·본문·링크·사진 준비 + 네이버 글쓰기' 버튼 클릭
4. WHENG 연결 페이지가 잠깐 나타난 뒤 네이버 글쓰기 화면으로 이동
5. 제목·본문·사이트 링크·대표 사진 입력 여부 확인
6. 태그/사진 위치/문장을 확인한 뒤 직접 발행

주의
- 네이버 로그인, 캡차, 발행은 직접 처리합니다.
- 네이버 SmartEditor ONE 화면 구조가 바뀌면 셀렉터 업데이트가 필요할 수 있습니다.


v1.2.0 변경사항
- 네이버에서 사진 첨부 시 본문이 사라지는 현상 수정
- 자동 입력 순서를 제목 → 시공사진 → 본문+사이트링크 순서로 변경
- WHENG 버튼 한 번으로 전부 입력되도록 보강
