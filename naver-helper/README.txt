WHENG Naver Blog Helper

기능
- WHENG 관리자에서 네이버 블로그 버튼을 누르면 solbi081 글쓰기 화면으로 이동
- 제목 자동 입력
- 시공 본문 자동 입력
- WHENG 공식 사이트 링크 자동 포함
- 등록된 시공사례 대표 사진 자동 첨부 시도
- 발행 버튼은 자동으로 누르지 않음

설치 (Edge/Chrome)
1. 이 폴더를 PC에 저장합니다.
2. Edge: edge://extensions 또는 Chrome: chrome://extensions 를 엽니다.
3. 개발자 모드를 켭니다.
4. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
5. 이 폴더를 선택합니다.
6. WHENG 관리자와 네이버 블로그를 새로고침합니다.

주의
- 네이버 SmartEditor 화면 구조가 바뀌면 자동 입력 셀렉터를 업데이트해야 할 수 있습니다.
- 네이버 로그인/2단계 인증/캡차는 직접 처리합니다.
- 자동 발행은 하지 않습니다. 내용 확인 후 사용자가 직접 발행합니다.
